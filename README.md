## 🌟 ویژگی‌های کلیدی پروژه

### ۱. رابط کاربری مدرن و تعاملی
- **جدول هفتگی پویا:** زمان‌بندی دقیق از ساعت ۰۶:۰۰ تا ۲۴:۰۰ بر اساس واحدهای ۱۵ دقیقه‌ای.
- **کشیدن و رها کردن پیشرفته (Drag & Drop):** جابجایی سریع کلاس‌ها با ماوس در دسکتاپ و پشتیبانی کامل از لمس (Touch) در گوشی و تبلت.
- **لودینگ اسپینر سراسری (Global Loading Spinner):** بارگذاری نرم و انیمیشن‌های شیشه‌ای (Glassmorphism) در هنگام دریافت، تعویض جدول و ذخیره‌سازی اطلاعات.
- **سیستم پیام‌های شناور (Toast Notifications):** اطلاع‌رسانی دقیق وضعیت‌ها (موفقیت، هشدار، خطا) به کاربر.
- **خروجی و ورود داده (JSON Export & Import):** پشتیبان‌گیری سریع از جداول و بازیابی آسان.
- **بهینه‌سازی شده برای چاپ (Print Friendly):** استایل‌های اختصاصی CSS برای پرینت تمیز جدول بدون المان‌های اضافی صفحه.

### ۲. دستیار هوشمند برنامه‌ریزی هفتگی (Smart Scheduler Wizard)
یک الگوریتم حل محدودیت‌های زمانی (Heuristic Constraint Satisfaction) به همراه اسلایدر ۴ مرحله‌ای مدرن:

```
[مرحله ۱: تثبیت برنامه‌ها] ➔ [مرحله ۲: افزودن فعالیت‌ها] ➔ [مرحله ۳: استراتژی و شروط] ➔ [مرحله ۴: پیش‌نمایش و اعمال]
```

- **مرحله ۱ (تثبیت برنامه‌ها):** امکان قفل کردن (Lock) فعالیت‌های موجود تا زمان آن‌ها تغییر نکند یا باز کردن قفل برای جابجایی هوشمند.
- **مرحله ۲ (افزودن فعالیت‌های متغیر):** افزودن کارهای جدید همراه با چیپ‌های سریع زمان (۴۵ دقیقه، ۱ ساعت، ۱.۵ ساعت، ۲ ساعت)، تعیین اولویت (ضروری ⭐، معمولی، دلخواه)، و ترجیح بازه زمانی (صبح، بعدازظهر، عصر/شب).
- **مرحله ۳ (استراتژی و شروط):**
  - **توزیع متوازن هفتگی (Balanced):** پخش یکنواخت کارها در تمام روزها بدون انباشتگی بار کاری.
  - **فشرده‌سازی حداکثری (Compact):** تکمیل فشرده روزهای اول برای ایجاد روزهای کاملاً آزاد در انتهای هفته.
  - **اولویت صبحگاهی (Morning Focus):** بهره‌برداری حداکثری از شیفت صبح (۰۸:۰۰ الی ۱۲:۰۰).
  - **اولویت عصرگاهی (Afternoon Focus):** تمرکز فعالیت‌ها در شیفت عصر و شب (مناسب برای شاغلین).
  - **فواصل استراحت (Buffer):** تعیین وقفه بین کارها (۱۵ الی ۶۰ دقیقه).
  - **محافظت از زمان ناهار (Lunch Break Protection):** جلوگیری خودکار از تداخل با ساعات ۱۲:۳۰ تا ۱۳:۳۰.
- **مرحله ۴ (داشبورد ارزیابی و امتیازدهی):** محاسبه درصد بهینه‌سازی (Score %)، گزارش تداخل صفر، خلاصه ساعات اضافه شده و پیش‌نمایش کارت‌ها با برچسب‌های تشخیصی.

### ۳. معماری امنیتی و استانداردسازی برای گیت‌هاب (Security First)
- **جداسازی کامل مشخصات حساس (.env & .env.example):** جلوگیری قطعی از نشت اطلاعات دیتابیس در گیت‌هاب با استفاده از فایل `.env` و پیکربندی `.gitignore`.
- **حفاظت وب‌سرور (.htaccess):** مسدودسازی دسترسی مستقیم مرورگر به فایل‌های `.env`، دایرکتوری‌های حساس و لاگ‌ها، به همراه هدرهای امنیتی مدرن:
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: SAMEORIGIN`
  - `X-XSS-Protection: 1; mode=block`
  - `Referrer-Policy: strict-origin-when-cross-origin`
- **محافظت در برابر حملات جعل درخواست (CSRF Protection):** تولید و اعتبارسنجی توکن امنیتی در تمام فرم‌های ورود/ثبت‌نام و تمام متدهای POST ای‌پی‌آی با هدر `X-CSRF-Token`.
- **امنیت نشست‌ها (Secure Sessions & Anti-Fixation):** اعمال پرچم‌های `HttpOnly`، `SameSite=Lax`، `Secure` و فراخوانی `session_regenerate_id(true)` پس از ورود و عضویت.
- **جلوگیری از حملات بروت فورس (Brute-Force Rate Limiting):** مسدودسازی موقت درخواست‌ها پس از ۵ تلاش ناموفق در صفحه لاگین.
- **اعتبارسنجی و پاکسازی عمیق ورودی‌ها (Deep Sanitization):** جلوگیری از حملات XSS و تزریق اسکریپت با فیلتر دقیق عناوین و اشیای JSON.
- **Prepared Statements با PDO:** بستن قطعی راه نفوذ SQL Injection در تمام کوئری‌ها بدون Emulate Prepares.
- **عدم افشای اطلاعات خطا:** جلوگیری از چاپ خطاهای PDO و مسیرهای سرور در خروجی JSON با ثبت امن در `error_log`.

├── .env.example          # نمونه تنظیمات محیطی برای گیت‌هاب

├── logout.php            # خروج ایمن و ابطال کامل کوکی سشن
├── index.php             # هدایت‌کننده هوشمند ورود/داشبورد
├── fonts/                # فونت استاندارد و زیبای فارسی IRANSansX
└── icons/                # آیکون‌های برداری SVG بهینه‌سازی شده

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/your-username/timetable-dplus.git
cd timetable-dplus
```

### ۲. ساخت پایگاه داده
فایل `schema.sql` موجود در ریشه پروژه را در دیتابیس MySQL یا پنل phpMyAdmin ایمپورت کنید:
```sql
mysql -u root -p < schema.sql
```

جداول مورد نیاز به صورت خودکار ایجاد می‌شوند:
- جدول `users`: نگهداری اطلاعات کاربران و هش رمزهای عبور
- جدول `schedules`: نگهداری جداول چندگانه، وضعیت پیش‌فرض و داده‌های JSON زمان‌بندی

### ۳. تنظیم متغیرهای محیطی (.env)
یک کپی از فایل `.env.example` با نام `.env` ایجاد کرده و مشخصات دیتابیس خود را وارد کنید:
```bash
cp .env.example .env
```

محتوای فایل `.env`:
```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=timetable_db
DB_USER=timetable_user
DB_PASS=your_strong_password
DB_CHARSET=utf8mb4

APP_ENV=production
APP_DEBUG=false
SESSION_LIFETIME=86400
SESSION_SECURE_COOKIE=false
```

### ۴. اجرا بر روی سرور
پروژه را درون وب‌سرور خود (مانند Apache، Nginx، XAMPP یا cPanel) قرار دهید. با مراجعه به آدرس دامنه یا `http://localhost/timetable/` صفحه ورود نمایش داده خواهد شد.

## 🔌 مستندات ای‌پی‌آی (REST API)

تمام درخواست‌های ای‌پی‌آی با فرمت `application/json` ارسال و دریافت می‌شوند و دسترسی به آن‌ها نیاز به سشن معتبر کاربری دارد. در متدهای POST ارسال هدر `X-CSRF-Token` الزامی است.

| متد | آدرس اکشن | کاربرد |
|---|---|---|
| `GET` | `api.php?action=list_schedules` | دریافت فهرست تمام جداول کاربر |
| `GET` | `api.php?action=get&schedule_id=1` | دریافت داده‌های کامل یک جدول بر اساس شناسه |
| `POST` | `api.php?action=create_schedule` | ساخت جدول جدید (`{"name": "جدول ترم جدید"}`) |
| `POST` | `api.php?action=rename_schedule` | تغییر نام جدول (`{"schedule_id": 1, "name": "نام جدید"}`) |
| `POST` | `api.php?action=delete_schedule` | حذف جدول غیرپیش‌فرض (`{"schedule_id": 2}`) |
| `POST` | `api.php` | ذخیره‌سازی داده‌های دوره‌ها در جدول فعال |
